# Phones Catalog

A responsive web application for browsing and exploring mobile phones. This project showcases a collection of phones with detailed specifications, allowing users to compare features and make informed purchasing decisions.

![Phones Catalog Screenshot](https://placeholder-for-screenshot.png)

## Live Preview

You can view the phones catalog here: [DEMO LINK](https://gglutt.github.io/phones-catalog/)

## Design Reference

The application follows a clean, user-friendly interface design with intuitive navigation and detailed product cards. The design prioritizes ease of use while providing comprehensive information about each device.

## Technologies Used

- React
- TypeScript
- SCSS/CSS
- HTML5
- ESLint (Code linting)
- Stylelint (Style linting)
- Vite (Build tool)
- BEM methodology (CSS naming convention)

## Getting Started

### Viewing Online

Visit the [live demo](https://gglutt.github.io/phones-catalog/) to view the phones catalog in your browser.

### Running Locally

1. Clone the repository:
```bash
git clone https://github.com/GGLUTT/phones-catalog.git
```

2. Navigate to the project directory:
```bash
cd phones-catalog
```

3. Install dependencies:
```bash
npm install
```

4. Start the development server:
```bash
npm start
```

5. To build for production:
```bash
npm run build
```

6. To deploy to GitHub Pages:
```bash
npm run deploy
```

## Features

- Responsive design that works on mobile, tablet, and desktop devices

- Detailed product pages with comprehensive specifications
